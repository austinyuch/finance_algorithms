流程 4 · 既有金字塔計算機 API

誰／何時：使用者計算等差/等比金字塔下單量。

cd invest_algorithms
uv run uvicorn api:app --host 127.0.0.1 --port 2224

端點：GET /api/pyramidArithmetic、GET /api/pyramidGeometric — 接受 budget、價格區間、交易次數、最小單位、sizing 參數、初始單位、toCsv。不可變既有基線。
