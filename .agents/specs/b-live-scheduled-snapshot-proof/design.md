# Design

References: `requirements.md`, `.github/workflows/daily-snapshot.yml`, `scripts/snapshot_schedule_report.py`, `tests/test_daily_snapshot.py`.

## Overview

This lane converts the scheduled snapshot proof from local-only smoke evidence to real GitHub Actions workflow evidence. It fixes the workflow timestamp bug found by run `27386918387` and records the proof boundary as `workflow_dispatch`.

## Architecture

- Workflow timestamps are generated by the runner shell with `date -u +%Y-%m-%dT%H:%M:%SZ`.
- `actions/upload-artifact` uses `if: always()` so partial JSON evidence is available for debugging if a later step fails.
- `tests/test_daily_snapshot.py` guards the workflow against invalid `github.run_started_at` usage.

## Test Coverage Declaration

- Unit/governance: workflow text guard plus existing schedule proof tests.
- Smoke: local dry-run report plus `snapshot_schedule_report.py` proof build.
- External: GitHub Actions `workflow_dispatch` run on the fixed branch, with artifact metadata inspected.

## Repo-side Closure vs External Execution Boundary

Repo-side closure covers workflow/test/spec changes. External execution is the GitHub Actions run; it can be performed from this workstation via `gh workflow run`, but its evidence source is GitHub Actions, not local command output.
