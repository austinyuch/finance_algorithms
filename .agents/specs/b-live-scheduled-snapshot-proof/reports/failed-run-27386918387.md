The workflow passed `--started-at "${{ github.run_started_at }}"` and `--finished-at "${{ github.run_started_at }}"`.
In GitHub Actions this context expanded to an empty string, causing:

```text
ValueError: schedule proof requires start and finish timestamps
```

## Fix

Use shell-generated UTC timestamps:

```bash
STARTED_AT="$(date -u +%Y-%m-%dT%H:%M:%SZ)"
...
--started-at "$STARTED_AT"
--finished-at "$(date -u +%Y-%m-%dT%H:%M:%SZ)"
```
